FOR MY PRINCESS ♡
=================

1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. That's it — no server or installation required.

Files:
- index.html: all five pages and the content
- style.css: responsive pastel styling and CSS animations
- script.js: page navigation, pleading NO button, typing letter, floating hearts, and hug surprise

Notes:
- The cat and puppy are emoji-based CSS-animated characters, so they work offline and do not rely on external GIF/video links.
- The Google Fonts import uses an internet connection when available; fallback fonts are built in.
- Personalize the wording in index.html and the letter text in script.js if you'd like.
